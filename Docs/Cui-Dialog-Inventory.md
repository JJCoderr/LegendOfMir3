# CUI 客户端对话框与面板场景清单

本清单从 `Mir3CuiClient.exe` 启动开始，按可到达的页面和业务入口盘点。依据是 [WinMain](../Client/CuiClient.cpp#L62)、[CUI 页面分派](../Client/Dialogs.cpp#L9985)、[客户端状态](../Client/CuiClientState.h#L69) 和 [Mir3.exe 对照记录](2026-11-22_reverse-mir3-dialog-audit-report.md)。原版 20 个有效局内窗口号均有对应 CUI 入口，编号 5、10、17 落入原版默认分支。编号 8 是共用弹窗，15 的编辑器由行会面板调起。

表格记录源码已接入的场景。冒烟脚本验证代表性的画面、状态转移及本地网关报文。需要实际服务端状态的分支在相应行列明。

## 运行冒烟测试

在仓库根目录运行。资源目录需要包含原版客户端的 `Data` 与 `CmList.dat`。

```powershell
& ./Client/Tests/Run-CuiDialogSmoke.ps1 -ResourceRoot 'G:/传奇3/宝藏传奇3' -Screenshots
```

脚本构建 Win32 Release 的 `Mir3CuiDialogSmoke`，使用回环地址上的临时端口启动测试网关。每组输出 `[RUN]` 和 `[PASS]`，失败时输出 `[FAIL]` 并返回非零退出码。全部通过时输出 `CUI_DIALOG_SMOKE_OK`。日志写入 `build-cui/dialog-smoke/<运行目录>/smoke.log`，可选的截图写入同目录的 `screenshots/`。不带 `-Screenshots` 时只运行断言。测试程序在该运行目录中创建自己的本地配置与缓存。

[PowerShell 入口](../Client/Tests/Run-CuiDialogSmoke.ps1) · [场景与断言](../Client/Tests/CuiDialogSmoke.cpp)

## 验证口径

- 启动和网关用例通过本地 WinSock 连接，校验登录错误、计费确认、角色创建与拒绝、游戏登录以及签退请求。部分前置提示使用通用 CUI 页面触发输入，原素材过场与真服画面需要单独比对。
- 局内回放从实际业务入口或网关回包驱动，覆盖一般打开、部分错误、独立窗交互和清理。每一个内部场景都可从上面的清单定位到代码。技能实际施放、照片上传实服结果、全部商店失败分支和真实双人交易的并发行为需要专项用例。
- 第一批五窗的静态原版底图与 CUI 本地实拍见 [原版对照记录](2026-11-22_reverse-mir3-dialog-audit-report.md)。像素图只能证明对应显示状态，服务端行为用报文和状态断言复核。

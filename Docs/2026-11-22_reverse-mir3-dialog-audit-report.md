# Mir3.exe 对话框与面板行为核查

核对范围是宝藏版 Mir3.exe 的局内窗口分派、CUI 当前入口和窗口之外的主要对话流程。界面验收关注控件、布局语义、文字和可见状态。行为验收关注按键与鼠标、请求与回包、失败后的恢复和离场清理。

原版 20 个有效局内窗口编号均可定位到 CUI 对应界面，其中包括合并到同一界面的编号。本轮新增 7、18、19、20、21 号独立窗口。窗口覆盖统计按是否可进入对应界面计算。详细行为、客户端样本中的休眠分支和联调项见下表。

Win32 Release 的 `Mir3CuiClient` 与 `Client` 均编译通过。原生 CUI 本地网关回放覆盖制作请求的准确字节、四种失败、重复点击和关闭窗口后收到结果，也覆盖四种仓库密码脚本链接、输入限长、取消无发包及提交后清空。回放日志在 `build-cui/npc-repair-native-test.log`。真实服务的端到端结果需按相关行的条目验证。

独立窗口的回放覆盖 `751` 装备槽、地图开启和装填、寄售检索与价格登记、信件读写及迟到的正文。日志位于 `build-cui/independent-windows-native-test.log`。`build-cui/independent-comparison-*.png` 将 CUI 运行截图与原版窗口底图并列，供布局复核。底图取自 `GameInter`，真实服务器中的同状态截图尚待采集。

后续修正以 `435820` 的五个构造参数为布局依据，将面板定位到原版 800×600 HUD 坐标。人物资料为 `(516,0,284,348)`，地图指令为 `(100,100,194,285)`，寄售查询为 `(60,20,720,440)`，寄售登记为 `(0,10,408,310)`，信件为 `(0,0,440,310)`。各窗使用各自底图和独立输入范围。打开登记后可从背包拿取物品并放入登记槽。登记期间保留查询结果，登记关闭时恢复查询窗。修正后的图片与回放见 `build-cui/independent-layout-comparison-*.png` 和 `build-cui/independent-layout-native-test.log`。

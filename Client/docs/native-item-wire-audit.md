# 原生客户端基础物品协议接入（2026-11-17）

本批完成服务端旧物品记录到原生客户端 MIR3 100 字节记录的基础适配；不是背包系统最终验收。

## 实现

- `Server/Def/Mir3Item.h` 明确字段偏移和小端写入；保留名称、模式、外观、基础防御/攻击、需求、价格、耐久。旧 MC/SC 与 MIR3 元素属性没有对应证据，未猜测填充。
- 每次角色连接建立数值实例 ID 与完整 12 字节旧标识的双向表。名称与当前拥有关系同时检查；断开后重新分配，尚不保证跨会话 ID 稳定。
- 背包、装备列表、新增物品统一发送新记录。背包排除穿戴物品。穿戴、卸装、使用及普通丢弃请求恢复旧标识再调用原逻辑。
- 修复卸装/替换装备成功后缺失物品返包：成功通知之后发送被卸下物品的 SM_ADDITEM。此修复编译通过，最终实服卸装回归尚未通过，不能标作验证完成。
- SendSocket 按实际发送缓冲区计算上限，超长时释放缓冲区；未验证满背包及网关批量发送容量。

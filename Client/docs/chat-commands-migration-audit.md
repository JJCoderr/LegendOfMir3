# 聊天命令、日志与调色板

依据Mir3/br_godot_test_261115的chat/scene_chat.hpp、chat/chat_log.hpp、chat/chat_submission.hpp及hud_view.cpp::chat_requested/append_chat_log；原版调色板入口401430、接收日志入口42F380。

## 本批修正

- GetChatColor的索引5改为RGB(150,150,255)，索引6改为RGB(255,255,80)，完整八色与参考数值一致。其他颜色不变。
- 私聊本地回显使用索引5前景、索引0背景；旧实现为白字蓝底。保留原有SendSay路径及上一批联系人记录。
- @snow精确匹配整条输入，带额外参数不触发本地天气开关；补充@chatsave精确匹配开关。界面按钮直接SendSay不经过输入框命令分支。
- 收到有效聊天消息后，以解码ANSI正文追加CRLF至Chat.txt；真实角色登录时启用工作目录日志路径，界面初始化清空路径，离线预览默认不写日志。开关与路径分离。
- 日志严格保留两个独立追加分支：关闭开关时，行会消息0次、其他聊天1次；开启时系统消息1次、行会1次、其他2次。超出1024字节编码上限的消息在既有解码入口被拒绝，不进入日志。无法打开日志文件不影响聊天显示。

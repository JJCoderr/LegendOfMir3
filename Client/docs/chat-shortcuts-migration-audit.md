# 联系人与快捷短语原生列表

依据：Mir3/br_godot_test_261115 的 client/src/chat/chat_submission.hpp，以及 hud_view.cpp 的 chat_shortcut_input、draw_chat_shortcuts、save_chat_shortcuts、load_chat_shortcuts。原版输入分派标记为427400。移植到CLIENT原生EDIT、GDI和DirectDraw，没有Godot依赖。

## 行为

- 输入以#开头时记住余下文本，不发送聊天请求；私聊/姓名 正文记录收件人和尾随空格，保留原有私聊发送路径。
- 联系人和短语各最多10项，重复记录不移动位置，超限移除最早项。
- 编辑框有焦点且没有通用弹窗或行会编辑器遮挡时，Ctrl显示联系人、Alt显示短语。数字1–9/0选择第1–10项，上下键夹取到首尾；两键同时按住时选择联系人，两个面板依次绘制。选择只填入输入框，不立即发送。
- 普通模式顶部405、展开模式365，左183、高165，宽99（普通短语100），行高16；背景及选中颜色沿用参考的预乘混合，宋体9pt、深灰与白色相差1像素绘制。原版短语文字允许超出99px背景，测宽超过358时取58个ANSI字节加省略号。
- 登录角色身份后读取Data/角色名(服务器名).slt/.mlt，ANSI文本、斜杠分隔。限制读取文件10240字节、单项1023字节、最多10项，与参考相同。文件名检查识别DBCS双字节，不能把中文尾字节误判为路径分隔符。离线夹具只在临时目录写测试文件并清理，不写Data联接资源。
- 离开编辑框由绘制的焦点判断隐藏列表；切换到其他应用清除修饰键，主窗收到的Ctrl/Alt也会更新状态，支持先按键再聚焦。按键选择没有额外音效调用，参考分支亦没有新增音效。

首次截图未保持按键状态，离线预览在初始系统焦点变化后列表被隐藏；现仅在截图夹具渲染前重新送出真实修饰键消息。生产绘制仍根据真实焦点及按键状态，不强制展示。随后新增先按Ctrl再聚焦检查发现清除焦点状态过早，改为应用失活时清除，最终检查通过。

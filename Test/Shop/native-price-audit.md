# 参考服商店价格核对

分析对象：`G:/传奇3/Mud3/Eiserver.exe`。
SHA-256：`14DF4090E15BEA233FCC871574B1F050E7BCD3945DD38660D225B286B2FF2C06`。
以下是 IDA 指令与调用关系的静态分析结果，尚不是原服务器动态交易验证。

## 已确认的行为

- `0x4985F0` 读取 `Merchant.txt`，在 `0x498846` 调用构造函数 `0x4E174C`。该构造函数在 `0x4E1787` 将商人偏移 `0x888` 的倍率初始化为 100。
- 脚本加载函数 `0x49F310` 在 `0x49F71F` 解析 `%` 后的整数，失败值为 -1；`0x49F727` 比较 55，只有大于等于 55 才在 `0x49F737` 更新倍率。低于下限或无效值保留原倍率，包括此前有效的倍率。
- 单价函数 `0x4D0E44` 按以下指令顺序计算：

```text
fild  base_price             ; signed 32-bit
fdiv  float32(100.0)         ; 0x4D0E80
fild  merchant.percent      ; merchant+0x888
fmulp
fld   extended80(1.1)       ; 0x4D0E84
fmulp
call  ROUND                 ; 0x402A44
```

`1.1` 的原始 80 位小端字节是 `cd cc cc cc cc cc cc 8c ff 3f`。
`ROUND` 使用 `fistp qword ptr [esp]` 转为整数；调用方只取 EAX。
默认 x87 控制字 `0x53A000` 为 `0x1332`，即扩展精度、最近值取整、平局取偶数。
不能直接用整数向下取整、C++ `round`，或默认双精度 `1.1` 替代而宣称完全兼容。
尤其需要验证中间浮点舍入对数学上半整数边界的影响。

- 普通商品列表 `0x4E0C38` 调用同一单价函数。
- 购买函数 `0x4CE1BC` 先调用 `0x4D0BC4` 取得物品基础价，再计算 `数量 * 单价函数结果`。余额不足或总价小于等于 0 时返回失败原因 3，不允许零价购买。
- `0x4D0BC4` 对批量普通物品返回标准价格；装备另有耐久和升级属性调整，尚未迁移验证。

## 已实现的普通商品价格

`ObjectMerchant.cpp` 使用 Win32 MSVC 内联 x87 指令，保留上述运算顺序和 80 位常量。计算前保存控制字，临时使用扩展精度、最近偶数舍入及屏蔽异常的 `0x037f`，计算后恢复原控制字，不改变游戏线程的后续浮点模式。
默认倍率为100；低于55、非数字和超出有符号32位范围的倍率保留先前值。零总价购买返回失败，金币、背包与库存不变。

| 场景 | 验证内容 |
| --- | --- |
| ShopBuy | 基础价10、默认倍率，单价11；金币25买两件后余额3，保存重登 |
| ShopPrice | 基础价11、倍率150，单价18；金币40买两件后余额4，保存重登 |
| ShopLowPrice | `%0` 不覆盖默认倍率；基础价11时单价12 |
| ShopInvalidPrice | 无效倍率保留默认100，基础价10时单价11 |
| ShopPriceBelowMinimum / ShopPriceMinimum | 倍率54被忽略，55生效 |
| ShopPriceRetained | `%150` 后的 `%54`、无效字符串和溢出整数均不覆盖150 |
| ShopZeroPrice | 基础价0报价为0，但购买失败且状态不变 |
| ShopPriceRounding | 基础价5/15/25/35得到单价6/17/28/38，每种买两件，扣款按已取整单价乘数量 |
| ShopSharedStock | 共享库存三件，两位角色余额78/89 |

基础价15的结果17并非直接对数学值16.5取偶数：按原指令的64位有效数字逐步舍入后，最终浮点数为 `16.5 + 1/576460752303423488`。基础价35的最终值恰为38.5，取偶数为38。两类边界必须同时保留。

## 范围限制

上述证据是参考服静态指令分析，联调使用本项目编译的客户端/服务器，不是运行原服进行交易。
实现仍只处理普通物品。装备耐久/升级附加价和原服特殊倍率文本语法未完成。普通商品定时补货已接入，见Test/README.md中的ShopRestock场景。
当前实现对超出非负有符号32位的报价不加入商品列表，总价超过INT_MAX则拒绝购买；不会复现原二进制整数溢出或异常行为。

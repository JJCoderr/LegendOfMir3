行为和网络消息见[原版怪物行为与消息规格](MonsterBehavior.md)。本页的动作表描述资源动作，不意味着某个同名协议消息必然进入该动作。

## 怪物外观总表

其他版本与待确认条目在「客户端版本」列标明来源。Zircon 与 1.45 同库同组的外观共用一行，保留 Zircon 英文标识和枚举 ID。只有 Zircon 证据的行标注 Zircon，候选 shape 写在核对依据中。资源对应可用于核对外观，服务端名称和刷怪配置仍取各自版本。

0x405E50 的普通外观映射使用库号 88＋shape 整除 10，帧组基址为 (shape % 10)×1000。非零索引表示归档登记了帧偏移。Zircon 条目的中文名称以能核对的国服名称为准。CastleFlag 使用 100 帧步长，组号由 Extra1 决定。

## Mon-20 外观 194–199 的复核

0x47EB58 登记 Mon-20，原版通用公式把 shape 194–199 映射到第 4–9 组。重新按 WIL 版本 5000 从 WIX 表头后第 28 字节读取，身体索引共 3700 条，阴影索引共 2122 条，均达不到第 4 组的首索引 4000。Zircon 明确引用第 4–9 组，因此可以确认这些是 Zircon 使用的额外资源组。各候选 shape 在 1.45 的实机或服务端记录中仍待确认。

- MonS-20.wix SHA-256 为 021a1eeca813470737c74123b2c646a629a488cd64e3fb946d657224f5010f91。

## 国服名称来源

按官方中文名和效果说明对照 Zircon 实现。标注「译名」的中文名称沿用参考译法。此处仅核对名称，客户端版本和 1.45 对应状态沿用表中记录。[盛趣《传奇3》官方技能说明](https://mir3.web.sdo.com/web7/news_con.html?id=297641)

本轮补核的名称及对应依据如下。

- QueenOfDawn 对应「黎明女王」。本地国服 Data/BossMonster.dat 的首领名称，和 Zircon 的独立首领 QueenOfDawn 对应。

本地安装目录另有 BOSSINFO.dat、EliteMonster.dat 和 RES_MONMAGIC.xml。按 GB18030 读取 BossMonster.dat 得到上述首领名。对 Mir3.exe 和安装目录中 46 个 DLL 的若干目标名称进行了 GB18030、UTF-16LE 和 UTF-8 明文检索，这些抽查词未在可执行文件或 DLL 中命中。安装包文件的 MD5 与官网公布的 1.9.3.1391 完整安装包相符，安装目录中数据文件的补丁版本未单独核实。[国服客户端下载页](https://mir3.web.sdo.com/web7/news_con.html?id=284264)

### 国服客户端怪物名称数据

Data/MonSet.dat 是 GB18030 名称列表，其中「狼人」「幽灵骑士」相邻，分别对应 Zircon 同批冰城外观 Werewolf 和 GhostKnight。MonSet.dat 的行序与 Zircon 编号和 1.45 shape 无直接对应关系。BossMonster.dat、EliteMonster.dat 提供首领和精英名称，BOSSINFO.dat 另含地图及首领说明。Mon.dat、MonEx.dat、monex_s.dat 为二进制数据，本轮未从中提取到可独立对应 Zircon 的名称。

### 新版客户端名称与外观记录的读取路径

以下地址取自本地新版 Mir3.dat 的离线解包 PE，SHA-256 为 eef5bc3ce72b8db3449389f21c367f9795dacbf919480c606717a49b052d7021。

- 0x5C8DBD、0x5C8DE2 拼接 MonSet.dat 的路径，0x5C8DF4 读取文本列表。0x5C8E1D 逐行取值，0x5C8E56 按名称查询，0x5C8ED4 使用名称及附加标志登记。行号用于读取列表元素，未作为外观表的键传入。
- 0x4F7D10 的路径加载基础表和 MonEx.dat，0x7110E7 可构造 Mon.dat 文件名。0x4F7BCC 以 0xB0 字节读取定长记录，使用记录首 DWORD 调用 0x479D98 入表，基础与扩展记录进入不同容器。样本分别读出 230 和 107 个互不重复的文件内键。
- MonEx.dat 的键 194–199 均存在，对应记录次 DWORD 依次为 4770、5180、5670、6160、6650、7220。新版资源记录支持这些编号的存在；MonSet.dat 中同样序号的位置出现的是蚂蚁将军、红甲虫、沃玛卫士、邪恶钳虫、白野猪、骨鬼将，未找到代码将两表按序号连接。尚未取得同一对象的名称与外观键，因此这六项仍保留现有译名和 1.45 候选状态。

# 原版退出过渡与角色选择页入口

## 分析方法与目标

2026-11-14实时IDA，目标哈希见exit-flow.md。上一轮按汇编字符串搜索438438h未找到读者，是因为IDA把位移显示为 `(loc_438437+1)[esi]`。本次遍历解码指令的o_displ操作数并按实际addr匹配，定位0x423D50。后续字段追踪应匹配数值位移，不能只匹配格式化文本。

## 过渡状态消费者0x423D50

主对象+0x438438为BYTE状态，+0x43843C为DWORD累计毫秒。函数每次先累加传入的帧毫秒，再分支：

| 状态 | 计时/画面行为 | 结束行为 |
|---|---|---|
| 0 | 累计时间清0 | 不绘制过渡 |
| 1 | elapsed<=2500时亮度=elapsed×0.1 | elapsed>2500时状态、计时清0 |
| 2 | elapsed<=2500时亮度=255−elapsed×0.1 | elapsed>2500时清状态/计时，调用0x421E80 |

退出101确认后写状态2、计时0。比较严格为 **>2500**，所以恰好2500ms还画亮度5；下一帧才离场，不是到2500就完成，也不是收到服务器确认才开始。

浮点常量0x4AF79C为float0.1，0x4AF3B4为255，0x4AF3AC为1/255。三个RGB分量为亮度/255；写入的alpha为0.39215687。矩形为(0,0)-(800,600)。0x423D50在0x424280末尾、普通HUD和通用对话框之后调用，所以过渡覆盖整个游戏视口，不只是地图。

绘制经0x47F3F0，混色模式6。0x492788的case6设置ALPHABLENDENABLE=1、SRCBLEND=1(ZERO)、DESTBLEND=3(SRCCOLOR)，即输出=原目标RGB×过渡RGB。alpha不作为这里的遮罩系数。实现应使用整屏乘法，不能套一般半透明黑色或只修改地图光照。

## 结束离场0x421E80

1. 将主对象this[895925]（本地游戏状态字段）清0。
2. 调用0x4217E0清理游戏场景。
3. 全局dword_902E2C低字节置2，并将当前场景指针dword_8FCDCC、dword_902E20指向dword_8F1D50。
4. 调用0x485040初始化新场景。
5. 根据窗口模式调用0x48B48C切换640×480、16位显示参数。

0x4217E0会清场景队列、地图/对象/HUD相关结构，停止声音，调用0x4214A0复位主对象并调用0x47BBB0断开旧连接；随后复制dword_4B97C8到dword_4B97E0，复制端口dword_4B97C4到dword_4B97DC，为下一场景连接准备地址。缓存保存不在这里，已在退出确认路径调用0x43EC60。

## 目标页是角色选择场景

0x485040读取Data/gameinter.wil与Data/Interface1c.wil，初始化输入框和角色选择按钮，并以保存的地址/端口调用0x47BAB0建立连接。末尾使用CmList200在显式坐标(155,150)打开类别0、类型2的通用提示框。其按钮/取消后续分支尚待完整追踪。

0x485AD0按内部BYTE+0x944分发，状态0绘制0x485CB0；状态2走0x486080，其他状态还涉及动画。0x485CB0确认的资源和行为：

- Interface1c帧50在(0,0)绘制背景，640×480页面。
- 从两个可见角色槽读取动画记录，每槽步长72；+0x26B0决定使用前两个或后两个角色记录。不能把游戏场景当前角色直接作为服务器角色列表。
- 动画记录带逐帧时间、首尾帧及动作编号；主体帧、+20阴影帧与+40附加帧分开绘制。
- 角色选择音乐Sound/SelChr.mp3在相关启动计时严格>1000ms后触发。
- 四个Interface1c按钮初始化位置依次为(440,93)、(79,243)、(259,49)、(28,438)，正常帧分别52、54、56、58；悬停/按下帧分别51/51、53/53、55/55、57/57。
- 另两个GameInter按钮位于(550,400)、(500,400)，普通帧1153和1152；+0x26B4控制是否绘制这两个按钮。不能在初始页面无条件画六个按钮。
- 悬停非4/5号按钮还会画提示矩形；0x486760负责额外文字/页面覆盖层，尚未完整恢复。

这些证据说明退出目标不是账号登录框。复用登录页或只隐藏地图都无法完成原版行为。

## 当前实现与验证

C++ ExitTransition已接入101确认：生成1009后开始过渡；每帧使用整毫秒累计（保留不足一毫秒余量），按原版严格>2500触发一次离场。独立最后绘制层使用blend_mul绘制800×600矩形，覆盖地图、HUD与对话框。

离场清当前人物/NPC/鸡、地图消息队列、掉落物、场景提示/血条/伤害、路径及地形缓存；停止地图音乐和人物音效，隐藏旧HUD/聊天输入并关闭旧对话框，清本地身份与退出限制。清理是Godot当前实现的状态覆盖，不代表原版所有尚未迁移对象的销毁路径都已复刻。

随后切换真实窗口和内容尺寸到640×480，直接解析外部Interface1c帧50背景、52/54/56/58四个按钮。+26B4默认0，因此两个附加按钮不画。连接提示使用GameInter1248，坐标(155,150)，文字CmList200。0x4207DD..0x42081C确认本次参数选择默认文字矩形(+23,+84)-(+331,+179)，故文字靠近短提示框底部；不能凭视觉喜好擅自改为框中央。类型2禁用所有按钮，当前输入路径阻止旧游戏快捷键及底层角色按钮。

离场依序发出game_connection_close_requested、character_selection_connection_requested，供会话层关闭游戏连接并重新连接角色选择端点；新连接发送序号复位。尚未实际建立TCP连接，因此页面停留在“正在下载角色资料，请稍等候。”。进入选择页后拒绝旧游戏的场景/NPC原始消息，也不能再从旧退出确认接口启动过渡。

Release构建通过，已添加Godot Window绑定以支持原版分辨率切换。原生--exit-transition验证1250中段亮度、2500仍绘制、2501离场、一次性事件和重启计时；Godot同名场景验证实际HUD与地图像素变暗、离场清理、通知顺序、640×480视口、等待提示输入阻断和旧消息拒绝。截图exit-transition-fading.png、character-selection-connecting.png来自实际视口。--exit-request与--exit-guard定向回归通过，未跑无关全场景。

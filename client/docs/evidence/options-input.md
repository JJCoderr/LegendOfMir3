# 选项窗口鼠标状态与按钮帧

## 原版证据

目标映像与哈希见 [选项窗口](options-panel.md)。2026-11-14 实时 IDA：`0x464010` 按下、`0x4640C0` 移动、`0x463500` 释放、`0x4641D0` 复位。共21个按钮槽，索引15未参与已恢复的选项绘制；索引0关闭，1/2音乐音效，3左右声道，4影子，5/6音量滑块，7..10本地四开关，11..14四服务器选项，16/17行会聊天与加入行会，18所有人聊天，19攻击方式，20玩家照片。

通用按钮：`0x41FC60` 移动在矩形内置state1、外置0，但state2不变；`0x41FCA0` 按下命中矩形置state2；`0x41FCD0` 先清state，再检查释放坐标，并按参数决定播放105号音效。它不要求先在同一按钮按下。`0x41FD70` 更换帧组时清state，所以服务器确认变化也应取消该按钮的按下态。

## 绘制规则

`0x41FAF0`：state0画普通帧；state1先画悬停底图再叠普通帧；state2只画按下帧。

| 状态组 | 普通帧 | 悬停底图 | 按下帧 |
|---|---|---|---|
| ON | 1292 | 1293 | 1295 |
| OFF | 1295 | 1294 | 1292 |
| 关闭 | 1221 | 1221 | 1222 |
| 攻击方式 | 1296 | 1296 | 1297 |
| 音量滑块 | 1291 | 1291 | 1291 |

此前一直绘制1293/1294，把普通状态错误表现为悬停；本批改为原版分层规则。文字与按钮位置保持原模块证据。

## 释放、移动和取消

按下按钮不改变设置；释放落点决定执行项。原版依序遍历按钮，命中后提前返回，因此只清除已遍历按钮状态，不能直接要求按下来源一致。窗口内移动时原按钮仍可保持按下，同时另一个按钮进入悬停。

`0x43CF40` 移动未命中任何窗口时调用 `0x4641D0`，清21个state和两个音量拖动标记。当前实现补齐普通按钮离开选项矩形的清理，以及关闭/重开和失焦清理；跨重叠窗口的分发与音量拖动边界仍待完整核对，不据普通按钮测试推断全部拖动已一致。

选项按钮释放、滑块按下使用已有105号点击音效。服务器1401只在变化位重设对应按钮帧/状态；相同位图保留预测与按钮状态，攻击模式值仍更新。

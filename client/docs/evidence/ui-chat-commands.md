# 界面聊天命令发送

## 原版依据

实时IDA核对47CA80：CM_SAY（3030）、recognition及三个参数均为零，正文经47C730六位编码。所有普通请求共用连接序号。使用集中协议常量与当前公共编码器。

43C130底栏20至22、463500选项11至14/16至19、434910骑马按钮、433340解除联盟均直接调用47CA80，不经过输入框处理427400。界面命令来自外部CmList资源，保留中文、空格和原编码；不硬编码命令文案。解除联盟改用共用发送入口，保留后续主页查询，仅发送一次聊天包。

系统选项预测状态仍依据旧确认值，不在发包时伪造确认；1401原包更新确认。骑马窗口的上马只在shape=0时发送4106，下马只在shape非零时发送4105，另两个按钮分别无条件发送4104/4105。聊天底栏“拒绝所有人聊天”命令末尾空格保留。

Release构建通过。独立ui_commands.gd覆盖七项选项、攻击方式、三项底栏拒绝命令、骑马按钮、按下不发送、重复请求、共享序号九次回绕、全包GBK字节及1401确认状态。仅原有apply_mount_reply已解码入口用于骑马按钮条件，不把它当作1300原包或人物上马动作验收。guild_wire.gd确认解除联盟共用入口没有重复包。截图ui-commands-options/reception/mount.png已展示。

首次ui_commands退出出现两个ObjectDB泄漏提示；详细日志重跑未复现，没有据此声称修复泄漏。真实服务器和偶发退出清理继续跟踪。

427400先让43E5B0处理编辑事件；非空输入若等于资源1425，管理员显示资源1426的1038名字框，否则1427提示，不发送原输入。4256B0的1038确认调用47CEE0发送CM_GUILDADDMEMBER。

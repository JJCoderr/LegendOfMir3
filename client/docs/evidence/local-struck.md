## 原版规则

- 31和1309均进入本地角色队列。参数0是当前HP、参数1最大HP、参数2伤害值，不能按坐标/朝向解读。16字节外观体偏移8是来源对象ID，偏移14的WORD为命中特效变体。
- 415AD0等待可消费动作状态，调用412500同步生命和外观；伤害非零才播放徒步15或骑乘32，保持朝向和骑乘字段。未命中也显示零值提示，尸体不添加伤害提示或播放受击动画。
- 412500使用400+变体创建命中特效，并从来源角色外观取武器字节用于受击音效。未知来源沿用原值。415AD0将帧间隔设为max(80,200-3*等级)，变体非零时增加15*已折叠31数量并记录特殊受击时间。
- 1309消费后复制一份31到同队列尾部，不能当作31的简单别名，也不能再走网络接收过滤。
- 42EC70处理本地31：距特殊受击不足500ms时先同步HP和最大HP，HP非零则丢弃动画消息；HP为零继续入队。
- 40D7F0在31入队前将折叠计数清零；已有队长大于1才扫描整队，取出旧31同步血条并累计字节计数，其他消息保持顺序。

```text
接收31/1309 -> 验证完整外观体
31 -> 特殊受击500ms过滤 -> 折叠旧31 -> 入队
当前动作结束 -> 取队首 -> 同步生命/外观/伤害提示
非尸体且伤害非零 -> 动作15/32 + 命中特效
设置等级相关帧间隔；1309复制31到队尾
死亡仍保持尸体；重新入场清除受击会话状态
```

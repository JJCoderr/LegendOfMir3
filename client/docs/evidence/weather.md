# 原版天气与 @snow

## 已确认的原版证据

目标为既有 mir3-map-review 分析库中的原版 1.45。以下结果已归档，后续实现直接引用；只有缺失字段或结果矛盾时补查 IDA，不重复分析已确认函数。未读取旧 Godot 业务工程。

- 4214A0：应用 +40 初始化为 1，+36/+44/+48 初始化为 0。427400 精确匹配 @snow 后翻转 +40，并继续发送 CM_SAY。此前聊天模型默认 false 不符合原版。
- 424280：在地图和人物绘制之后、名字/聊天/HUD之前，+40 开启时先按 +44 绘制雾，再按 +36 更新和绘制雪花。关闭开关不更新粒子。+48 是独立天气分支，不受 @snow 控制。
- 42EE00：换图消息参数2低字节是亮度，高字节是天气。清除 +36/+44；天气1设置雪和雾，销毁并重建雪系统；天气2只设置雾；天气3设置 +48。这里没有先清除 +48，不能与即时天气消息混为一谈。
- 4282C0 的 SM_DAYCHANGING（46）清除 +36/+44/+48，再按天气1/2/3设置。天气1重建雪系统。头参数0低字节选择亮度基值，参数1低字节保存昼夜模式，参数2整个WORD是天气。原来的scene_ambient.update(p[2])把天气误当昼夜，本批更正为p[1]。
- 421A30/42EE00/4282C0：雪系统参数为 500 个槽、宽 800.0、高 600.0。虚表 4AFB30：初始化465F40、销毁465600、绘制466340、更新466030、生成4666A0、配置465F60。
- 465F60：水平力10、垂直力100、摩擦参数-0.05。464E00设置四顶点为单位正方形[-0.5,+0.5]；每个粒子绘制宽高由自身scale决定，而不是资源图片尺寸。
- 4666A0：初始y随机[-300,0]，x随机[0,800]；vy随机[70,100]，vx随机[-30,30]；寿命[2500,7000]毫秒；质量1000+rand()%1000*0.001；大小随机整数[2,6]+rand()%1000*0.001；RGB前两分量随机[120,150]、第三分量多100。初始age=0，frame=0，frame_elapsed=0，frame_interval=300。
- 401710：闭区间随机数为 min+abs(rand()-rand())%(max-min+1)，不是均匀分布替代。
- 466030：每次更新最多生成5个，按槽序遍历；步长为max(1,毫秒/17)*0.02。age加原始毫秒。当age<=life且y<600时更新力、速度和位置；否则在age-life<=255时以BYTE(life-age-1)限制各RGB分量并停止运动，超过255释放槽。触底时仍沿用此寿命差值规则。帧计时严格>300时归零，唯一纹理帧始终为0。
- 4653A0/465400：阻力=-velocity*(-0.05)，累计加速度 += (阻力+外力)/mass；velocity += 累计加速度*步长；position += velocity*步长。不能替换为常规重力公式。
- 466340：资源调用47F3A0(4,86,500+frame)。世界坐标x-400、300-y，单位四边形缩放scale。材质RGB为粒子RGB/255、alpha=1/255；混合ONE / INVSRCALPHA，纹理alpha乘材质alpha。
- 46B580/46B6F0：雾使用库86帧550；四边形[-400,400]×[-300,300]再缩放(5,2)，初始位移0。全局帧计数先加1，<800时位移(-1.9,-0.2)，<1600时(+1.9,+0.2)，否则计数归零。屏幕y轴相反。颜色(100,200,200)/255，材质alpha=1/255；492788模式2指定ONE / INVSRCCOLOR。

## 实现伪代码

```text
收到51/634：按已有队列成功载入地图后，天气=参数2高字节
收到46：昼夜目标=参数1；天气=参数2整个WORD
选择天气：
    雪=(天气==1)，雾=(天气==1或2)
    46清除独立天气3标志；换图保留该标志；天气3再置位
    雪天重置500个空粒子槽
每次游戏更新（开关关闭则保持状态）：
    若雾开启：按1600帧往返规则移动雾
    若雪开启：依槽序生成最多5个；推进年龄、累计力、速度和位置
    到寿命或底边：停止运动，按原BYTE规则衰减颜色，寿命超过255毫秒后释放
绘制：地图人物 → 雾背景拷贝与帧550 → 雪帧500 → 场景光照 → 既有特效/文字/HUD
输入@snow：翻转默认true的总开关，同时继续CM_SAY；既不清空粒子也不重建雾
```

粒子使用独立MSVCRT算法随机状态，以免影响其他客户端随机调用；原版共享随机流的逐粒子序列不可直接对齐，但保留随机公式、范围及调用顺序。46参数0参与的环境亮度基值生成尚未完整恢复；本批只纠正昼夜字段并接通天气，不宣称46全部逻辑完成。

### 更新遍历的原版边界

补查原因：按常规粒子发射器理解会得到“每帧5个”，与反编译中的提前结束条件矛盾。4661A5..4661B4汇编确认正常更新后processed>=active即返回，因此初始仅生成1个，正常寿命阶段不会继续填空槽。4662F1、466339的释放/淡出分支直接跳4661B6继续扫描，不经过提前结束检查，才可能生成后续粒子。实现保留此行为，不能为了视觉密度自行补成常规发射器。

## 验证

Release构建；hud_checks --weather覆盖随机范围、原版初始1粒子/淡出继续扫描、255/256毫秒边界、开关冻结、雾799/800/1600帧以及换图与即时天气标志区别。weather.gd仅测试天气模块及关联昼夜字段，不跑全游戏流程；验证雪/雾外部原资源、真实粒子像素、命令冻结恢复与CM_SAY、畸形包无副作用、完整WORD天气、昼夜渐变及切图重建、离场清理。截图weather-clear、weather-snow-fog、weather-paused、weather-fog-only保存到client/build/screenshots。受影响聊天分派及照明模型进行定向回归。

未进行原版同状态逐像素比较；随机种子与原版共享流不作逐帧等同承诺。天气3、完整环境基值及实服联调仍未完成，不将本批测试作为全客户端一致性的证明。

# 地图持续事件

4282C0 的 804 读取四字节六位编码正文，识别号用于查重，第一 WORD 是类型，后两 WORD 为格坐标。类型4/5 分别构建效果16/22。44D0B0 保存事件编号，并以 46EF60 查 MInfo 的 MAGIC 段。两者用 Magic 库81，帧区间 [640,650) 和 [920,925)，间隔100/150毫秒。44D150 在累计时间严格超过间隔时推进一帧并清掉余数，末帧后回到首帧。首帧由原版随机偏移选择。44D270 使用资源染色和混合模式。

805 按识别号结束持续效果。类型5另触发330–334及220的后续效果，仍待接入。类型3/6的辅助事件队列和类型9的多段效果尚需单独核对。

```text
804 → 校验头和正文 → 若编号已存在则维持原状态 → 创建格坐标持续效果
场景更新 → 按原间隔推进一帧 → 相机移动时重新定位
805 → 移除匹配的持续效果
成功换图或离场 → 释放当前地图效果
```

Windows Release、map_events、map_door、level_up 通过。定向渲染截图为 map-events-active.png。混合和事件声光仍需按原版同状态对照。

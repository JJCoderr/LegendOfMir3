# 原版1.45功能清单IDA核查

核查日期：2026-11-14。对象为既有 `mir3-map-review` IDA会话，镜像 `Mir3-unpacked-analysis.exe`，SHA256：`08f68b794bfb28803d1132c02b26d2595dba309be5b2b475ae0cdfe6a752f8aa`。本轮只读分析，不修改共享IDB、不运行游戏测试。

## 结论与覆盖边界

48个模块可以继续作为功能分类，但原清单不是完整规格：本轮确认了补丁调用、仓库密码、NPC制作、对话控制标记、显示与声道设置、武器升级提示等缺项。窗口18及服务器结果动画已有具体代码证据，正式用途仍需核实。

本轮重新检查启动参数、窗口构造/切换/绘制、键盘和鼠标入口、聊天提交、游戏消息分派及队列，并沿新增线索反编译关联函数。其他模块结合既有IDA专题检查归属，**不等于本轮逐条重新证明所有细项**。尚不能宣称已穷尽MIR3.EXE所有功能，更不能把功能清单当成实现或验收完成证明。

- [survey.json](survey.json)：2006个函数、768条字符串。只对业务范围内的字符串与调用关系进一步采集，未逐个恢复2006个函数。
- [inventory.json](inventory.json)：选定地址区间的378条字符串及交叉引用、1370个函数的直接调用；不是整个镜像的所有字符串与间接调用。
- [dispatch-inventory.json](dispatch-inventory.json)：重新提取消息、窗口和键盘分派。消息主选择器为184个switch编号及12个显式相等编号，共196项；未把嵌套参数分支计为消息编号。
- 窗口绘制0–22中有20个实际分支，5/10/17为默认分支。`436A30`反编译失败，保留反汇编核对，未根据失败结果推断缺失功能。
- [E-imports.md](E-imports.md)：分析镜像标准导入枚举为空。间接API槽和部分库名仍可观察，但API枚举不足以证明系统能力已经查全。
- 本目录`.c`为本轮IDA伪代码证据，不是项目实现。部分请求地址位于函数内部，应以文件内函数声明确定实际函数入口；反编译变量类型和字段含义仍需人工核实。

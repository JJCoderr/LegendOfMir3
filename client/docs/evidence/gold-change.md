# 金币变化及原版共用提示

原版4282C0 case 653（42ADF7..42AE5B）：先调用4832D0(106,0,0,0)，再计算新金币减旧金币；42AE12使用SUB，42AE14另以CMP结果与0比较，所以差值按DWORD回绕后视为有符号数。仅差值大于零时填入CMList1471并调用41C120；无论差值正负或零都写入新金币DWORD。参数字不参与处理。消息名对应开源定义SM_GOLDCHANGED，业务不使用裸消息数值。

41C120反编译确认忽略第二个颜色参数，实际调用401430(2)、401430(7)并传给4366D0，即前景0xFFFFFF、背景33023。升级1469提示也走该函数，须同步纠正此前按传入颜色11861940显示的差异。

106音效按SoundList.wwl映射读取，当前位置参数为0，使用非位置音效播放器，受音效开关及音量控制。原资源106映射为106.wav；不复制资源。不把金币余额当人物身份，也不以INT_MAX截断。

# 本地角色死亡与重新入场

2026-11-14实时核验415AD0、412000、411700、415740、416E70、42EE00、42F190，目标身份同map-wire.md。415AD0按角色队列消费32/34并调用412000；后者采用参数0/1位置、参数2方向及光照、16字节外观，选择动作19。32直接设置死亡并停最后帧，34先播放死亡动作。416E70在动作19到末帧时设置死亡、HP与血条为0；尸体保持动作19末帧。412000保留原骑乘字段，但死亡绘制不用马匹。

415740对本地53更新HP/MP/最大HP及伤害数字，不清除死亡；415AD0没有本地1316复活分支，1321实际是强制走步且不能清除死亡。42EE00换图不清死亡字段；42F190经本地入场初始化重新建立角色状态。因此不把回血、远端复活码或普通切图当作本地复活。

```text
32/34完整外观消息与强制位移共用FIFO
当前本地动作结束后出队死亡：更新格/方向/外观，终止路线与待执行动作
32 -> 尸体末帧；34 -> 动作19逐帧播放，结束固定末帧并HP归零
死亡中禁止本地移动/攻击；FAIL不得恢复为站立；服务器移动不使尸体行走
53即时更新数值但不解除死亡；尸体更新周期继续将HP置零
50重新入场 -> 清除死亡与残留动作，按新入场外观建立人物
```

其他技能复活入口仍需目标版本证据，本批不推断。死亡音效复用HumanActions的144/145映射。

415AD0在消费消息后检查死亡标志并强制动作19末帧，因此死亡期间的强制位移仍刷新包推导的锚点/外观，但不播放行走。实现保留该差异，不能简单丢弃全部死亡期间的位移回包。

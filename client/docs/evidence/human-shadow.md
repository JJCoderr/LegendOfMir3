# 人物、武器与坐骑阴影

2026-11-14通过IDA复核414870、48F4AB、48F7C7，复用此前怪物阴影已确认的48F397混色。目标身份同map-wire.md。

414870先绘武器影、坐骑影和身体影，再绘人物彩色图层。身体资源头的模式48不投影，49取偶数扫描行并向右剪切、纵向压缩，50保持轮廓；使用资源shadow_x/shadow_y定位。已完成死亡的尸体强制模式50，并在身体原偏移上加(3,2)。人物加载、有限动作和附件帧现在保留原WIL阴影元数据，按需读取原档案，不导出素材。

武器影使用48F7C7：只取奇数行，以武器offset_y减16后的整数半值为基准，再按扫描行号向左剪切；蹲姿8、武器37、无武器、动作25以上及尸体不绘武器影。坐骑影从Horse的10000+(相对动作帧-2320)%400独立帧组读取，与马匹外观帧分开缓存。头发没有额外独立投影。

普通阴影受ShadowBlend控制：关闭时实心黑影，开启时原RGB565的13/32源权重混合。状态模式1或人物淡入期间强制混合影，保持已有状态着色与人物层序。

```text
每个人物绘制：
  满足武器条件 -> 奇数行武器投影
  骑乘动作 -> Horse独立阴影帧
  身体 -> 按资源模式投影；尸体改平影
  再按前后关系绘制坐骑、武器、身体和头发
阴影使用同一场景背景拷贝混合，不覆盖前方对象层序
```

验收：Release构建通过；human_shadow.gd在两种ShadowBlend配置下验证身体、武器、骑乘、尸体图层，并直接比较阴影区域像素，输出HUMAN_SHADOW_UI_OK。human_status_visual.gd相关回归输出HUMAN_STATUS_VISUAL_UI_OK。两项约7秒，无引擎错误或退出泄漏，未运行完整场景测试。截图human-shadow-weapon-1.png、human-shadow-mounted-1.png及human-shadow-corpse-1.png。

原版同状态逐像素、视口边界裁剪细节以及更多衣服/武器/坐骑资源覆盖仍待验收；本批不替代这些最终一致性检查。

# 地图掉落物与拾取请求

实现前对照见 ../../RERENCES.md 和 ../../../server/RERENCES.md。当前显示/名字依据早期 C++ 参考，旧原版证据仅覆盖输入拾取路径；完整 1.45 像素一致性尚未验证。

610 从三个参数读取 x/y/looks，六位解码名字（至 NUL、最多 39 ANSI 字节），从配置目录的 Data/Ground.wil 原地读取图像，物品按 ID 去重；611 按 ID 移除。GroundItems 独立模型保留同格物品与到达顺序。绘制按格子中心减整数半宽/高，不使用 WIL 偏移，位于同排人物之前；当前采用 Godot 黑色半透明影子，原版精确混色待核验。鼠标所在格的首物品显示淡黄名称和阴影，窗口遮挡时不显示。

左键点击当前格、人物空闲且无待走路径时发 pickup_requested(1001, player_cell)；无需掉落物缓存存在。持续左键沿用 >0.3 秒重复输入路径，未移植 Zircon 250ms 冷却。不会直接增加背包或删掉物品，等待服务器消息。当前还没有本地死亡/区域等完整会话状态，不能以 HUD 未初始化的 HP=0 替代这些状态判定。

验证：Release CMake；hud_checks --ground-items 覆盖同格多物品、ID 去重、名字边界、居中取整、幂等移除；Godot --ground-items 覆盖 610/611、真实 Ground 图像、名称优先顺序、路径不受物品阻挡、原地请求、窗口阻挡与移除后提示切换。截图 bichon-ground-items.png、bichon-ground-item-removed.png 来自实际 800×600 视口，名字为测试数据。

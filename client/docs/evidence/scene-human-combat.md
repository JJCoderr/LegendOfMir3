# 战斗站姿与受阻退回

依据旧项目 extension.cpp / remote_actor_action.hpp 中已分析的 0x412C80、0x414220、0x411D40、0x411480 行为，按功能移植到场景人物模型。

攻击启用 5001 ms 站姿计时，计时未结束时再次攻击不重置。有限动作完成后，未骑乘人物采用动作 7（560 起始、每方向 10 帧、3 帧循环、200 ms 间隔）。超时回普通站立；计时跨移动和其他动作继续流逝。骑乘优先显示动作 29，复活清除战斗站姿。上下马重置 idle 相对帧，避免四帧站立切换到三帧时越界。

7 号场景消息进入动作 23（1840 起始），按已知目标格及方向反推一格起点。每次有效移动节拍推进两帧，达到第 4 帧退回保存的起点并播放有限动作 7，恢复动作结束后消费下一条队列消息。积压不会让该动作额外追帧，减速仍按场景移动节拍过滤。它是已分析的受阻/退回分支，不代表所有击退或冲撞消息均完成。

资源继续从配置目录按帧读取。武器是否绘制按动作区间而非骑乘字段决定，与旧 ActorAppearance::weapon_action_frame 的 action >=25 过滤一致，避免骑乘状态下的非骑乘动作误隐藏武器。

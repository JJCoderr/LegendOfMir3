# NPC 买入结果

- 42A8DF–42A8EB（650）用识别号的完整 DWORD 更新金币，调用 478750 移除当前详情列表选中的单件。
- 42A8F5–42A954（651）用识别号表示失败分支。1 同样移除当前详情行，随后显示 1437。2 和 3 保留详情行，显示 1438 和 1439。
- 47CC70 和 47CCB0 都发送 1014。详情物品的第三 WORD 为零，批量商品的第三 WORD 为数量。批量商品没有详情列表行可移除。物品入包由 200 消息单独触发。

```text
收到 650：写入服务端余额 → 若正在查看有效详情，移除选中行
收到 651：按识别号处理失败 → 分支1移除选中行 → 显示提示
收到 200：背包接收物品记录
```

Windows Release 与 buy_wire.gd、sell_wire.gd 和 npc_wire.gd 通过。买入用例退出时报告两个 ObjectDB 实例。截图为 npc-buy-stock-and-bag.png 与 npc-buy-sold-out.png。实服和原版同状态像素对照待验收。

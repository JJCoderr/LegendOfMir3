# 私聊与快捷短语历史菜单

## 原版输入依据

实时IDA数据库mir3-map-review：4373E0绘制私聊收件人菜单，437A60绘制短语菜单，仅在聊天输入框具有焦点、无模态对话且对应Ctrl/Alt按下时显示。两个修饰键同时按下时两层均绘制，短语层后画。

47B430原编辑框子类在数字1..9时转发2031/2032的0..8索引，数字0转发索引9；Ctrl优先于Alt。4277D0将消息交给437210/4378B0，只有索引小于列表长度才更新选中项，越界时仍调用原选中项填入。437240用`/%s`设置收件人（历史文本自身保留末尾空格），4378E0直接设置完整短语，均将光标移至文本末尾。

43D760的38/40分支处理上下键：Ctrl选择收件人，Alt选择短语；向上最低0，向下最高数量减1，不环绕。435180将两组选中项初始化为0。原菜单没有鼠标点击选择处理；47B430的Delete走编辑框默认处理，43D760无历史删除分支。此前TODO中的“删除历史项”是未验证假设，已撤下，不据此新增按钮；历史仍按十项上限自动淘汰。

高度均165，行距16；文字影色657930位于左上+4/+4，白色文字位于+5/+5。选中条位于+1/+2，宽度减2、高16。背景收件人RGB200/100/0、短语150/150/50，alpha180/255；选中收件人255/0/0、短语50/50/200，alpha120/255，保留原混合路径。

短语测量宽度超过358像素时取前58个ANSI字节并追加三个点。TextOut不按99/100像素菜单宽度裁剪，文字可能延伸至面板右侧；插入仍用完整短语。实现复用原GDI字体测量和文字绘制。

## 实现及验证

ChatSubmission新增两组选中项与边界规则，HUD在输入框默认处理前拦截相应数字/方向键；只有菜单选择被消费，未聚焦时数字键仍走快捷物品栏。焦点丢失或松开修饰键隐藏菜单；模态姓名框不显示、不插入历史，窗口失焦清理修饰键状态。插入不发送网络消息，按Enter才进入现有聊天提交逻辑。

chat_shortcuts_checks.hpp（hud_checks --chat-shortcuts）验证独立选中项、越界保留、上下边界、空列表和私聊前缀。chat_shortcuts.gd验证真实Ctrl/Alt输入、数字0、第十项、中文长短语完整插入、普通/展开菜单、松键隐藏、焦点和模态隔离、网络请求数量。截图chat-shortcuts-contacts.png及chat-shortcuts-phrases-expanded.png已用真实视口检查。

受影响模块验证chat_submission.gd、quick_items.gd通过。没有运行全游戏场景集成测试，按AGENTS要求留待模块全部完成。尚需与原版同状态逐像素对照及实服完整验收。

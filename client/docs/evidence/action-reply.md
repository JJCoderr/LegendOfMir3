# 本地动作确认与拒绝

目标镜像同map-wire.md。2026-11-14实时IDA复核：4282C0在六位解码前检测首字节43，去掉+后调用427C50。4B519C、4B51A4分别为GOOD、FAIL。427C50按前缀匹配，允许后缀；GOOD将主界面+3583488清零（本地角色+403544）；FAIL调用415E60。斜线后的时钟采样不决定确认/拒绝结果，本批不实现其统计警告。

415F90在移动/攻击发起时保存+403644/+403648格坐标与+403652朝向，并置+403544等待标志。417E10在等待或动画执行标志非零时拒绝后续输入；418660右键路径同样检查。416E70累计帧毫秒，严格大于8000才清零等待标志，不回滚。GOOD不截断进行中的动画。415E60在角色死亡标志未置位时恢复保存坐标和朝向，清除位移与攻击效果状态，切换徒步/骑乘站立，通过415F50重设地图视口，清零等待计时。

```text
动作实际执行前：保存当前格与方向，等待确认=true，累计时间=0
下一次动作输入：若等待确认则拒绝；动画仍独立推进
+GOOD任意后缀：等待确认=false，不改变动作、坐标、方向
+FAIL任意后缀：若角色存活且有保存状态，恢复坐标方向并重置本地动作/相机
每帧：等待时累计毫秒；累计>8000仅解除等待
换图、角色切换、退出：清除本地保存状态，防止旧场景回滚
```

实现覆盖已接通的走、跑、普攻、挖矿及蹲下动作。服务器强制传送/击退等二进制位置消息继续归移动与状态模块，不以本批代替。

# NPC 仓库

- 700 打开背包模式3，确认按钮 1230/1231。47C060 发送 1031，识别号为商人，前两 WORD 为物品编号，第三 WORD 为数量，正文为名称。701 的前两 WORD 为剩余和存入数量；702/703 显示 1449/1450。
- 704 正文为斜线分隔的六位编码 100 字节物品，第三 WORD 为记录数。4798D0 切入模式2，使用1261详情窗口；478850 在本地翻页。
- 47CD30 发送 1032，字段与存入相同。705 第一 WORD 为仓库剩余量，第二 WORD 为背包数量更新值；为零的仓库剩余量删除该行。706/707 使用1445/1446。
- 复用原资源网格和背包模式，完整物品交付仍由背包消息处理。

```text
700 → 选背包物品 → 1031 → 701/702/703
704 → 本地翻页、选仓库物品 → 1032 → 705/706/707
关闭或离场 → 清空仓库交互状态
```

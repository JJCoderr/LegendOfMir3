# 人物状态、灯光与血条校验消息

2026-11-14实时IDA核对目标镜像（身份同map-wire.md）的415AD0、411BA0、407C00、407C20与4282C0。远端413F90及本地415AD0将801/807/808送往虚表+116；4AF510和4AF5FC均指向411BA0，不是+120的4117D0。

411BA0读取参数0/1合成状态DWORD，参数2按有符号WORD保存攻击速度。状态bit1置位时，将当前与保存的血条校验字段都设置为同一次时钟采样；清位时只清当前值，保存值不变。因此原血条可因两值不相等隐藏。消息随角色FIFO消费，不能即时修改正在进行的本地动作门禁。远端状态也保留到后续无新状态体的动作，供已实现的减速计时使用。

4282C0对1100/1101按本地身份或已存在远端对象走即时虚调用，与动作队列无关。1100经+52的407C00取参数0低字节更新灯光属性；1101经+56的407C20刷新当前及保存血条校验值。协议表保留历史SM_OPENHEALTH/SM_CLOSEHEALTH名称，同时添加本版本语义别名SM_ACTOR_LIGHT/SM_ACTOR_BAR_REFRESH；807改名SM_ACTOR_STATUS，保留原SM_807数值定义。

```text
801/807/808 -> 本地或远端人物FIFO -> 当前动作可消费时
  保存状态DWORD、int16攻击速度
  bit1置位：当前token = 保存token = 时钟
  bit1清位：当前token = 0
1100 -> 即时灯属性 = 参数0低字节
1101 -> 即时当前token = 保存token = 时钟
```

已验证：Release构建；hud_checks --scene-light；actor_status.gd输出ACTOR_STATUS_UI_OK，检查移动/蹲姿中状态延后、灯光即时生效、807不污染灯光、负速度、三种状态码、清位隐藏血条、1101恢复、新身份清理及换图灯光保留。melee_cooldown.gd输出MELEE_COOLDOWN_UI_OK，验证排队速度回包之后的实际攻击门禁。两项视口短测试集中执行，无引擎错误或退出对象泄漏；未运行整场景集成。

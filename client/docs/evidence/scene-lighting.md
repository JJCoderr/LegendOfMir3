# 场景照明与地图入场

## 接口与时序

`change_map(map_id, name, spawn, ambient_mode=0)` 从配置根目录的 Map/<map_id>.map 读取地图。编号只允许 ASCII 字母、数字、下划线和短横线；禁止路径。先在临时 MapTerrain 中解析并验证可走落点，成功后才替换地图。包括同图同名重入，都会清远端人物/NPC/怪物、掉落物、移动路径、旧消息清理队列、头顶发言/伤害、NPC 对话和小地图内容；保留背包、聊天记录及本地人物基础数据。文件编号与显示名称分别保存。失败不更改场景或环境亮度。

`apply_scene_message(encoded,key)` 接收已分帧消息；46 无附加消息体，第三个 16 位参数送入 SceneAmbient::update。这里沿用旧 1.45 分析；两个早期 C++ 参考版本使用 wParam/wTag，不能混用。尚未接真实 SM_NEWMAP/SM_CHANGEMAP 原始消息，不能将已解码入口称为完成实服换图。

模式 0/1/2 的入场亮度为 255/15/85。入场立即生效并取消旧渐变。46 在模式变化时启动 50ms 时钟，每次增减 0.5 亮度，绘制取整数部分；重复相同模式不重新计时，换目标重置计时，抵达目标停止。未知入场模式取 10，未知渐变模式目标为 0，保持既有原版分析中的区别。没有离线自动昼夜循环或调试按键。

## 资源索引与网格

地图头 28 字节，22/24 偏移为小端宽/高；地砖表占 width×height/4×3，后续每格 14 字节，按 x×height+y 排列。灯字位于格数据 +12，小端 16 位；非零且 `(word>>4)&255 < 10` 有效。半径用高两位索引 `{4,8,12,20}` 格。颜色索引 0..4 分别为 (173,198,214)、(90,140,165)、(41,57,115)、(222,198,99)、(41,115,49)，5..9 为白色。直接读取外部 map，不导出或拷贝游戏资源。

场景使用 18×19 颜色顶点，间隔 48×32，灯中心使用原偏移 +8/+29。半径内按像素距离线性衰减，每个 RGB 通道对所有光源累加并上限 255。对角线按最后覆盖该网格的光源相对象限选择；灯源顺序为地图行/列、本地人物、可见远端人物。当前默认本地灯属性 0：半径 4、颜色 (100,100,100)；远端默认属性 0：半径 4、颜色 (10,5,5)。807 人物灯属性已接入，见 actor-light.md；真实装备联调和法术光源尚未接入。

## 绘制层次

主节点绘制地形、物件、掉落、人物；scene_light_layer 用 `blend_mul` 将网格 RGB 与场景相乘；hud_base 在其后绘制头顶名称/发言/血条、HUD 基底；原有装饰和 hud_tail 对话框继续在上层。白天亮度 255 时跳过灯网格，避免额外改变颜色。照明不修改纹理或整个节点 modulate，界面保持原色。

## 证据与验证

原版既有分析地址和参考版本差异见 ../../RERENCES.md 的环境亮度条目；本批未新增 IDA 分析。采用旧 mir3_1.45 的 gameplay.cpp、spell_light.hpp、extension.cpp::scene_lighting、world.gd::_draw_world_spell_light 按功能迁移，所有运行逻辑均为 C++。

- Release CMake 构建。
- `hud_checks.exe --scene-light`：50ms 边界、半步截断、相同模式保留时钟、目标钳制、入场取消渐变、未知模式区别、灯源偏移、半径、颜色累加饱和及对角线。
- Godot `--scene-light --screenshots`：昼/夜/暮入场，真实 46 包驱动渐变，错误消息体不修改状态；165 个网格顶点的截图颜色与输入乘积比较（至少 141 个误差小于 0.035），并确认存在彩色灯区与暗区；HUD 250×110 区域昼夜逐像素相同，夜景 NPC 对话单独截图。
- `--scene-text --screenshots`：本次绘制分层影响的名称、聊天、人物移除定向回归。

截图保存于 client/build/screenshots/scene-light-{day,night,dawn,night-dialogue}.png，提交前在对话中展示。与原版同状态逐像素对照、装备/法术灯、光源离场细节仍未全部验收；本测试证明迁移公式与本实现的渲染一致，不等于原版全画面一致。

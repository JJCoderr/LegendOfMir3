# 升级反馈：以原版为唯一行为基准

## 来源约束

2026-11-14用户明确不再复用旧Godot工程。本功能独立依据原版IDA与配置目录原资源实现；此前对旧工程的查看不作为验收证据，也不移植其代码。已提交的其他功能如后续发现偏差，仍以原版纠正。

## 原版处理链

4282C0的SM_LEVELUP分支：参数三为0时，recognition写经验DWORD，参数一低字节写等级，调用本地人物虚表+16，参数7/4/0；创建449480对象，调用4495D0以422及当前人物坐标初始化，加入全局特效链表，输出资源1469通知。参数三为1时recognition作为远端人物ID查找，只作用于该人物，不写本地等级经验。其他参数三值直接返回。

421070构造this+3179944时调用415420，后者设置虚表4AF58C；虚表+16指向406750。此函数确认为人物动作设置：动作参数7、方向4、时长覆盖0，按人类动作表的三WORD读取起始帧/数量/间隔，写动作120、方向121/122、当前帧124并清计时128。因此升级动作必须独立于效果播放恢复。

## 原版资源与绘制

4703E0读取并原位解密MInfo.dat，按CR行分隔并跳过两个字节；#SPELL/#MAGIC/#EXPLOSION分别分配表。逗号触发整数转换，末尾闭括号之前的未逗号终结数值不转换。46EE20的前19参数映射起止帧DWORD、间隔/资源库/编号WORD、14个BYTE；后续成员为固定常量，不能读取任意额外列替代。

46EF60按#MAGIC表中WORD+12匹配编号，步长48。当前原资源422记录为2020/2030帧区间、80ms、库137，光半径3/4，内RGB100/150/200，外RGB150/200/250，染色240/180/100，混合2、透明度字节1、光相位上限0。资源未复制、未写出解密内容。

449480设置+292照明启用。4495D0对422进入LABEL_71：循环关闭、目标位置模式开启、人物指针清零；因此保持发生升级时的地点，不随人物移动。创建时音效编号为10*422+10002，即14222。绘制44A500使用资源偏移叠加屏幕投影，染色与透明度来自BYTE240..242/257；492788模式2设置DSTBLEND=INVSRCOLOR，49295D恢复SRCBLEND=ONE，故模式2为source + destination*(1-source)，不能用普通alpha混合代替。

## 播放结束不能简化

44B7E0只在累计时间严格大于间隔时前进一帧，并清零累计；末帧结束时夹到end-1，将状态置为1，不直接销毁。44A110在光计时严格大于200时进入收缩：状态1时计时改为150，若内半径<=1或外半径<=内半径则状态2，否则两个半径均减1。活动状态则按光相位上限循环。424280逐项调用虚表+12更新，仅状态2时从链表删除；之后绘制链表剩余对象。因此状态1确实继续绘制末帧。

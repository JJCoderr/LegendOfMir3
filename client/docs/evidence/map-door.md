# 地图门

- 452A40：格记录 +9 高位标记可触发门，低7位是组号。452AA0：该标记存在且 +11 高位为零时挡路。
- 612/614 使用头前两 WORD 的坐标取组号。452B00/452BC0 在坐标周围 [−8,+10) 的矩形中，对所有低7位组号匹配的格设置或清除 +11 高位。包括只负责绘图的同组格。
- 415F90 调用 47CBB0，以识别号发送门号，前两 WORD 发送坐标，命令1002。613 以 CmList 1472 发聊天提示。
- 帧偏移由传统 C++ 参考的 GetDoorImgIdx 补证：+11 高位置位后加入低7位偏移。Windows 验收使用比奇原地图的真实门格。

```text
移动朝向关闭的门 → 发送门号及坐标，保留静态障碍
612 → 更新附近门组、重绘并允许通过可走格
613 → 显示锁门提示
614 → 关闭门组并重新阻挡
换图 → 从原地图资源读取初始状态
```

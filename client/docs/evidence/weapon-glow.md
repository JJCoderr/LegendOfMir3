# 特殊武器46光效

2026-11-14实时IDA复核414870、415160、492788、448C30。目标身份同map-wire.md；库148对应MonMagicEx4，复用既有运行时库映射。

414870在武器图层绘制之后检查外观46，并按男女选择相对动作帧加1900或3900调用415160。武器前后层由原武器顺序表决定，光效紧跟对应层，不放到统一最上层。动作25及以上不绘武器，因此骑乘动作不产生该光效；下马回到徒步动作后恢复。其他武器、空武器和不可用的武器图像不进入此分支。

415160用47F3A0(1,148,index)取原帧，按原帧偏移绘制；492788模式2使用ONE/INVSRCOLOR，即source + destination*(1-source)。复用已验证的level_effect着色器，在当前武器层前拷贝局部背景，不影响其他不透明批次或阴影混合。

415160无论特效帧是否可读取，均在人物屏幕锚点+(24,16)调用448C30：内半径2、外半径5格、内外RGB均为(40,40,250)。在已有18×19场景光网格加入该蓝光。每帧重新收集可绘制武器产生的光源，避免换装、骑乘或离场残留；白天地表满亮时沿用已有照明跳过规则。

```text
人物动作 -> 查武器图层顺序
绘制武器46 -> index = (女?3900:1900) + 相对动作帧
  读取MonMagicEx4帧 -> 按原偏移与模式2混合
  添加锚点+(24,16)蓝色光源
动作或装备改变 -> 下一帧按当前条件重新建立光效和光源
```

验收：Release构建通过；weapon_glow.gd输出WEAPON_GLOW_UI_OK，检查男女原帧组、攻击帧推进、照明网格蓝通道变化、换装/骑乘关闭及下马恢复。human_shadow.gd相关回归输出HUMAN_SHADOW_UI_OK。两项约7秒，无引擎错误或退出泄漏。实际截图weapon-glow-male-female.png、weapon-glow-attack.png。未执行全场景集成。
